v4.83 baseline: CRLF normalization + first clean 0/0 compile

Establishes the locked v4.83 base as the single source of truth and adds the
strict local build tooling required by the project workflow.

Line endings
- Normalized all 10 sources to strict CRLF (byte-safe, non-ASCII preserved).
  Six files were bare-LF: COttoBlockManager, COttoCorrelationFilter,
  COttoMarketStructure, COttoNewsFilter, COttoRiskManager, OttoDefines.
- Added .gitattributes pinning *.mq5/*.mqh to eol=crlf.

Bug fixes
- COttoTradeManager: replaced deprecated PositionGetDouble(POSITION_COMMISSION)
  which raised compiler warning 89. Commission is now summed from deal history
  via the new GetPositionCommission() helper, reusing the existing
  HistoryDealGetDouble(..., DEAL_COMMISSION) convention already established in
  COttoOrderManager::LogClosedTrade(). Behaviour for negative/zero commission
  and the 7.0/lot fallback is unchanged.
- .gitignore added so .ex5/.log artifacts and pristine snapshots never commit.

Tooling
- _tools/build_check.ps1: stages a temp MQL5 tree mirroring the terminal layout,
  compiles via the MetaEditor CLI /log and fails the gate on any error or warning.
- _tools/normalize_eol.py: byte-safe CRLF normalizer with a --check mode.
- README.md documenting layout, build gate and version policy.

Verification
- Result: 0 errors, 0 warnings (MetaEditor64 5.0.0.6182, X64 Regular).
- otto.ex5 produced (147584 bytes).

No trading logic was changed in this commit.
